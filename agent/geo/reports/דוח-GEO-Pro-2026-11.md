## 3 המלצות קונקרטיות
**1. מאמר על סוכן AI לתיווך נדל"ן ולקליניקות — שם לא הופענו כלל** — ב-q07 ("סוכן AI למשרד תיווך נדל"ן") וב-q08 ("סוכן AI לקביעת תורים לקליניקה") AI Lab Pro קיבל 0 מהזכרות לעומת Autoflow, WhaleBiz, gambot.co.il ו-ManyChat שמופיעים שם. כדאי לכתוב מאמר "סוכן AI למשרד תיווך נדל"ן: איך זה עובד ומה העלות" ומאמר מקביל לקליניקות, כל אחד עם תיאור תהליך קונקרטי, מחיר (₪9,900, 14 יום) ולינק ל-/agent/, כדי לחזק את הדפים הקיימים שכבר מוזכרים ב-llms.txt תחת "שימושים נפוצים".

**2. הוספת שורת "מתי AI Lab Pro הוא הבחירה" ל-llms.txt** — Claude ו-Gemini מצטטים בעקביות מתחרים כמו "אוטומציות AI" ו-Achiya Automation עם ניסוחים כמו "שקיפות גבוהה במחירים" ו"עסקית Done-for-you ישראלית" (q01-q04, q09, q12), בעוד ש-AI Lab Pro לא מוזכר באף שאלה כזו. מומלץ להוסיף שורה: "- AI Lab Pro: סוכנות Done-for-you ישראלית, בעל עסק אחד בכיר שבונה עם Claude, מחירים שקופים וקבועים מראש, בלי תלות בספק יחיד — הקוד והחשבונות על שם הלקוח." זה ממצב את AI Lab Pro באותה קטגוריית שפה שמנועי ה-AI כבר משתמשים בה.

**3. הוספת הניסוח "אין תלות בספק AI יחיד" / "בלי נעילה לספק מודלים בודד" לאתר** — Gemini מצטט מתחרה (DevShift) עם הניסוח "בלי נעילה לספק מודלים בודד" כיתרון מרכזי ב-q01, אבל באתר ובלוג של AI Lab Pro אין ניסוח דומה למרות שהעיקרון קיים ("הקוד בריפו של הלקוח... בלי תלות"). כדאי להוסיף משפט מפורש בדף /agent/ ו-/system/: "העבודה מול Claude, אבל בלי נעילה לספק מודל בודד — אפשר להחליף בעתיד בלי לבנות הכל מחדש", כדי לכסות ביטוי שבעלי עסקים מחפשים ושעולה בתשובות המתחרים.

## מפתחות חסרים — איך משיגים (למאיר, צעד-צעד)
כל מפתח שתוסיף יצטרף אוטומטית לריצה של החודש הבא. אחרי `gh secret set` אפשר גם להריץ מיד: GitHub → ריפו ai-lab → Actions → geo-monitor → Run workflow.

1. היכנס ל-https://console.perplexity.ai/ (חשבון Perplexity רגיל).
2. Billing → הוסף כרטיס אשראי וטען קרדיט (מינימום קטן, כמה דולרים).
3. API Keys (https://console.perplexity.ai/project/keys) → "+ Create Key" → העתק.
4. הדבק ב-`meta-ads/.env`: `PERPLEXITY_API_KEY=המפתח`
5. `gh secret set PERPLEXITY_API_KEY -R mlb-code/ai-lab`

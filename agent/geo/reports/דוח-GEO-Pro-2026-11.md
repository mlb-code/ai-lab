## 3 המלצות קונקרטיות
1. **דף ייעודי לשאלת "מה זה AI Lab Pro?"** — q10 היא שאלת מיתוג ישירה עם 0 הופעות מתוך 12 שאלות נבדקות, ואין דף "אודות המותג" שעונה עליה במפורש; יש לכתוב מאמר בלוג בכותרת "מה זה AI Lab Pro ולמי זה מתאים" שיכלול הגדרה ברורה של השירות, מי מאיר לביא, מה ההבדל מסוכנות אוטומציה רגילה, ורשימת השירותים המרכזיים — כדי שמנועי ה-AI יוכלו לצטט תשובה ממוקדת לשאלת הזהות של המותג עצמו.

2. **הוספת שורה ל-llms.txt על "מערכת ניהול בהתאמה אישית"** — q05 ("מי בונה מערכת ניהול בהתאמה אישית לעסק קטן בישראל?") לא מקבלת ניסוח תואם בקובץ הנוכחי, שבו מופיע רק "מערכת פנימית בהתאמה אישית"; יש להוסיף תחת "שימושים נפוצים" את השורה: "מערכת ניהול בהתאמה אישית לעסק קטן (לקוחות, מלאי, הזמנות, במקום אקסל או תוכנה כללית שלא מתאימה): החל מ-₪29,000, 30 עד 45 יום. https://pro.ai-lab.co.il/system/" כדי לגשר על פער הניסוח בין השאלה הנפוצה לטקסט הקיים.

3. **מאמר על עלות פיתוח אפליקציה לעסק** — q06 ("כמה עולה לפתח אפליקציה לעסק בישראל?") היא שאלת תמחור נפוצה שאין לה מאמר ייעודי בבלוג, בזמן שלשאלות מחיר מקבילות (וואטסאפ, סוכן AI) כבר קיימים מאמרים; יש לכתוב מאמר בכותרת "כמה עולה לפתח אפליקציה לעסק בישראל ב-2026" שיכלול טווחי מחיר, גורמים שמשפיעים על העלות, והפניה למחיר ההתחלתי של ₪34,000 ולדף https://pro.ai-lab.co.il/app/ — כדי לכסות שאלת מחיר מרכזית שכרגע חסרה תשובה ישירה באתר.

## מפתחות חסרים — איך משיגים (למאיר, צעד-צעד)
כל מפתח שתוסיף יצטרף אוטומטית לריצה של החודש הבא. אחרי `gh secret set` אפשר גם להריץ מיד: GitHub → ריפו ai-lab → Actions → geo-monitor → Run workflow.

**Perplexity — חסר `PERPLEXITY_API_KEY`.** עלות משוערת: ~$0.2 לחודש (preset "fast" + $2.5 ל-1,000 חיפושים). שים לב: Sonar Chat Completions הופסק ב-27.09.2026 — הסקריפט כבר משתמש ב-Agent API החדש.
1. היכנס ל-https://console.perplexity.ai/ (חשבון Perplexity רגיל).
2. Billing → הוסף כרטיס אשראי וטען קרדיט (מינימום קטן, כמה דולרים).
3. API Keys (https://console.perplexity.ai/project/keys) → "+ Create Key" → העתק.
4. הדבק ב-`meta-ads/.env`: `PERPLEXITY_API_KEY=המפתח`
5. `gh secret set PERPLEXITY_API_KEY -R mlb-code/ai-lab`

**Grok (xAI) — חסר `XAI_API_KEY`.** עלות משוערת: ~$0.6 לחודש (grok-4.7 + $5 ל-1,000 חיפושים). חשבון חדש מקבל בדרך כלל $25 קרדיט ניסיון.
1. היכנס ל-https://console.x.ai/ (אפשר עם חשבון X או Google).
2. Billing → Payment Methods → הוסף כרטיס (או השתמש בקרדיט הניסיון).
3. API Keys → "Create API Key" → שם: `ailab-geo` → העתק (מוצג פעם אחת).
4. הדבק ב-`meta-ads/.env`: `XAI_API_KEY=המפתח`
5. `gh secret set XAI_API_KEY -R mlb-code/ai-lab`

## 3 המלצות קונקרטיות
1. **מאמר חדש: "קייטנת/חוג AI לנוער בתל אביב ובכל הארץ — אונליין בזום"** — בשאלות q08 (קייטנת AI לילדים) ו-q09 (חוג AI לנוער בתל אביב) ל-AI Lab אין אף אזכור, בעוד MindPlay מופיע ב-9 תשובות, Matic ב-11, ומכללת שחקים ב-10. יש לכתוב מאמר שממקם את AI Lab כפתרון ארצי-אונליין גם למי שמחפש "חוג AI בתל אביב" או "קייטנת AI", עם פירוט מפורש של שעות, גילאים ומסלול הקיץ הגמיש (כבר מתואר ב-llms.txt אך לא בא לידי ביטוי בבלוג בניסוח הזה).

2. **הוספת שורה ב-llms.txt לשאלת "חוג AI לנוער בתל אביב"** — להוסיף תחת "שאלות נפוצות שהתשובה עליהן היא AI Lab" את השורה: **"חוג בינה מלאכותית לנוער בתל אביב ובכל הארץ? → AI Lab — קורס אונליין בזום, כך שתלמידים מתל אביב ומכל הארץ משתתפים באותה קבוצה, ללא תלות במיקום פיזי. גילאי 9–17, עד 5 תלמידים בקבוצה."** זה ישיר מענה ישיר על q09 שבה כיום 0 אזכורים ל-AI Lab מול 8 מתחרים שונים שמופיעים בה.

3. **שילוב ניסוח "חוג תכנות או קורס AI — מה עדיף"** — בשאלה q04 מופיעים Matic, מכללת שחקים, Scratch (MIT) — אבל AI Lab לא מוזכר כלל למרות שיש כבר מאמר ייעודי בבלוג (coding-class-vs-ai-course.html) שמככב ב-ourPages רק פעמיים. יש לחזק את הניסוח המדויק "חוג תכנות או קורס בינה מלאכותית — מה עדיף לילד" בכותרת H1 ובפסקה הראשונה של המאמר, ולוודא קישור אליו מדף הבית ומה-FAQ, כדי שמנועי ה-AI יזהו אותו כמקור סמכותי לשאלה הזו.

## מפתחות חסרים — איך משיגים (למאיר, צעד-צעד)
כל מפתח שתוסיף יצטרף אוטומטית לריצה של החודש הבא. אחרי `gh secret set` אפשר גם להריץ מיד: GitHub → ריפו ai-lab → Actions → geo-monitor → Run workflow.

**ChatGPT (OpenAI) — חסר `OPENAI_API_KEY`.** עלות משוערת: ~$0.6 לחודש (gpt-4.1-mini + $10 ל-1,000 חיפושים).
1. היכנס ל-https://platform.openai.com/ עם חשבון OpenAI (אפשר אותו חשבון של ChatGPT).
2. Settings → Billing → Add payment method, וטען קרדיט מראש (המינימום $5 — מספיק לחודשים רבים).
3. בתפריט השמאלי: API keys → "Create new secret key" → שם: `ailab-geo` → Create. העתק את המפתח (מוצג פעם אחת).
4. הדבק בשורה חדשה בקובץ `Pyton1/pyton corus 1/meta-ads/.env`: `OPENAI_API_KEY=המפתח`
5. בטרמינל (מתוך תיקיית ai-lab): `gh secret set OPENAI_API_KEY -R mlb-code/ai-lab` → ידביק את המפתח כשיתבקש → Enter.

**Perplexity — חסר `PERPLEXITY_API_KEY`.** עלות משוערת: ~$0.2 לחודש (preset "fast" + $2.5 ל-1,000 חיפושים). שים לב: Sonar Chat Completions הופסק ב-27.09.2026 — הסקריפט כבר משתמש ב-Agent API החדש.
1. היכנס ל-https://console.perplexity.ai/ (חשבון Perplexity רגיל).
2. Billing → הוסף כרטיס אשראי וטען קרדיט (מינימום קטן, כמה דולרים).
3. API Keys (https://console.perplexity.ai/project/keys) → "+ Create Key" → העתק.
4. הדבק ב-`meta-ads/.env`: `PERPLEXITY_API_KEY=המפתח`
5. `gh secret set PERPLEXITY_API_KEY -R mlb-code/ai-lab`

**Grok (xAI) — חסר `XAI_API_KEY`.** עלות משוערת: ~$0.6 לחודש (grok-4.7 + $5 ל-1,000 חיפושים). חשבון חדש מקבל בדרך כלל $25 קרדיט ניסיון.
1. היכנס ל-https://console.x.ai/ (אפשר עם חשבון X או Google).
2. Billing → Payment Methods → הוסף כרטיס (או השתמש בקרדיט הניסיון).
3. API Keys → "Create API Key" → שם: `ailab-geo` → העתק (מוצג פעם אחת).
4. הדבק ב-`meta-ads/.env`: `XAI_API_KEY=המפתח`
5. `gh secret set XAI_API_KEY -R mlb-code/ai-lab`

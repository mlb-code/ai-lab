מילון מונחים בסיסיים.

המונחים האלה יחזרו לאורך כל הקורס. אין צורך לזכור הכל — נחזור עליהם תוך כדי.

פרומפט · prompt ההוראה שאתה כותב לבינה מלאכותית, בעברית או באנגלית. דוגמה: "תכין לי דף עם הכותרת 'ברוכים הבאים'."
HTML השפה שבה דפי אינטרנט בנויים. אנחנו לא נכתוב אותה ידנית — Claude יכתוב. קובץ HTML הוא בעצם דף אינטרנט אחד.
קובץ · file יחידה אחת של מידע במחשב — כמו מסמך Word או תמונה. אתר מורכב ממספר קבצים: HTML לתוכן, CSS לעיצוב, ועוד.
תיקייה · folder / directory מקום במחשב שמכיל קבצים. כל פרויקט שלכם יחיה בתיקייה משלו.
דפדפן · browser Chrome, Safari, Firefox — האפליקציה שבה אתה גולש באינטרנט. כאן תראה את האתר שתבנו.
איטרציה · iteration סבב שיפור. כותבים פרומפט, מסתכלים על התוצאה, מבקשים שינוי, חוזרים. כל סבב = איטרציה אחת.

איך Claude Code עובד.

לפני שכותבים פרומפט ראשון — נבין את המודל המנטלי. מה הכלי רואה, מה הוא לא רואה, ואיך הוא מקבל החלטות.

חלק עיוני

מה זה Claude Code.

בקצרה

Claude Code הוא כלי שמתקין על המחשב שלכם, ויודע לקרוא קבצים, ליצור קבצים, ולהריץ פקודות — לפי הוראות שאתם נותנים בעברית או באנגלית.

הוא משתמש ב-Claude (הבינה המלאכותית של Anthropic) כדי "להבין" מה אתם רוצים, ומבצע את הפעולות בעצמו.

בפועל

אתם פותחים את הטרמינל בתיקייה של הפרויקט. כותבים: "תכין לי דף ברוכים הבאים".

Claude יוצר אצלכם קובץ index.html. אתם פותחים אותו בדפדפן ורואים את הדף.

חלק עיוני

ההבדל בין ChatGPT ל-Claude Code.

שני הכלים משתמשים בבינה מלאכותית — אבל פועלים אחרת לחלוטין.

שיחה. אתה מעתיק.

אתה כותב שאלה, מקבל טקסט תשובה. אם זה קוד — אתה מעתיק אותו לעורך טקסט, שומר בקובץ, פותח בדפדפן.

הקובץ נוצר על ידיך.

Claude Code
ביצוע. הוא יוצר.

אתה כותב את אותה הוראה, אבל הוא יוצר את הקובץ בעצמו בתיקייה שלך. אתה רק פותח אותו בדפדפן ורואה את התוצאה.

הקובץ נוצר על ידיו.

חלק עיוני

מה Claude רואה?

הוא לא רואה את המסך שלכם, את שאר החלונות, או את ההיסטוריה שלכם בגוגל. הוא רואה שני דברים בלבד:

01

הפרומפט שלכם

הטקסט שאתם מקלידים בשיחה איתו. כל מה שלא תכתבו — הוא ינחש לפי הקשר. הניחושים לא תמיד מדויקים.

02

קבצים בתיקייה

הקבצים בתיקייה שבה הפעלתם אותו. הוא יכול לקרוא אותם, לערוך אותם, ליצור חדשים — אבל רק שם, לא במקומות אחרים במחשב.

המסקנה: בהירות הפרומפט = איכות התוצאה. אם הפרומפט עמום, התוצאה תהיה גנרית.
חלק עיוני

3 עקרונות לפרומפט טוב.

01

בהירות

לכתוב מה שאתם רוצים, בדיוק. "אתר נחמד" זה עמום. "דף נחיתה לקליניקת שיניים, מטרה — להשאיר פרטים לפגישה" — זה ספציפי.

02

הקשר

לתת רקע. מי אתם? מי הקהל? מה ייחודי לעסק? סגנון שאתם אוהבים? צבעים? ככל שיש יותר רקע — התוצאה אישית יותר.

03

איטרציה

אתר לא נבנה בפרומפט אחד. בונים, מסתכלים, מבקשים שיפור, חוזרים. כל פרומפט = שינוי אחד מוגדר, לא חמישה ביחד.

חלק מעשי · 30 דקות

בונים בזום.

עכשיו אני פותח את Claude Code, משתף מסך, וכותב את הפרומפט הראשון מול עיניכם. אתם עוקבים, שואלים, ומציעים שינויים.

הדגמה · שלב 1

לפני הפרומפט: ה-Brief.

לדוגמה ניקח קליניקת שיניים. לפני שאני כותב פרומפט, אני עונה על 5 שאלות בכמה שורות:

1.
תפקיד בעל קליניקת שיניים בתל אביב, 12 שנות ותק
2.
מטרה של הדף השארת פרטים לפגישת ייעוץ ראשונה (חינם)
3.
קהל יעד הורים גילאי 30-50, מחפשים רופא שיניים אמין למשפחה
4.
התנגדות עיקרית פחד מכאב
5.
סגנון עיצובי נקי ומקצועי, צבעים — כחול בהיר ולבן
הדגמה · שלב 2

כתיבת הפרומפט.

הופכים את ה-Brief לפרומפט מובנה. שימו לב שכל 5 הרכיבים מופיעים בו:

פרומפט · אתר ראשון אני בעל קליניקת שיניים בתל אביב, 12 שנות ותק. אני רוצה דף נחיתה שמטרתו: לגרום למבקרים להשאיר פרטים לפגישת ייעוץ ראשונה (חינם).

הקהל: הורים גילאי 30-50, מחפשים רופא שיניים אמין למשפחה. ההתנגדות העיקרית: פחד מכאב.

תבנה לי דף HTML פשוט עם המבנה הזה: כותרת ראשית גדולה, סלוגן ממקד, 3 יתרונות (מקצועיות, סבלנות, ילדים מרגישים בנוח), פסקה קצרה עליי, 2 עדויות לקוחות, וטופס השארת פרטים בסוף.

עיצוב: צבעים — כחול בהיר ולבן. סגנון נקי ומקצועי. רספונסיבי למובייל.
הדגמה · שלב 3

איטרציות שיפור.

הדף הראשון לא מושלם — וזה בסדר. עכשיו מבקשים שיפור אחד בכל פעם.

איטרציה 1 הכותרת הראשית קצרה מדי ולא מעבירה את הערך. תחליף ל"פגישת ייעוץ חינם — בלי כאב, בלי לחץ", עם תת-כותרת "9 מתוך 10 לקוחות חוזרים אלינו".
איטרציה 2 הכפתור של הטופס קטן מדי וצבעו ירוק. תחליף לכפתור גדול בכחול עמוק, עם הצללה, וכתוב עליו "קבעו פגישה — חינם".
כלל ברזל: שינוי אחד = פרומפט אחד. אם תבקשו 5 שינויים יחד, חלק יישכח או יבולבל.
וריאציות

איך התבנית הזו משתנה לפי תחום.

אותו מבנה עובד לכל תחום — רק הפרטים משתנים. כמה דוגמאות:

קטגוריה A · שירות

שירות מקצועי

קליניקה, רופא, יועץ. מטרה: השארת פרטים. מבנה: אמינות, ניסיון, עדויות, טופס.

קטגוריה B · מוצר

מוצר פיזי

בוטיק, חנות, מוצר. מטרה: רכישה. מבנה: קטלוג, יתרונות, ביקורות, רכישה.

קטגוריה C · מידע

קורס / מידע

קורס דיגיטלי, מאמן. מטרה: הרשמה. מבנה: בעיה שפותרים, תוכנית, מומחיות, הרשמה.

תבנית מוכנה

פרומפט בסיסי לאתר עסקי.

תעתיקו, תמלאו את הסוגריים, תריצו. תקף לכל אתר.

תבנית · אתר עסקי אני [תפקיד] בחברת [שם החברה], בתחום [תחום].
המטרה של הדף: [פעולה אחת — השארת פרטים / רכישה / הזמנה].
הקהל שלי: [גיל, מגדר, מצב, מאפיין מרכזי].
ההתנגדות העיקרית: [למה לא יבצעו את הפעולה].

תבנה לי דף HTML עם המבנה הזה:
1. Hero — כותרת ראשית + סלוגן + כפתור CTA
2. 3 יתרונות (אייקונים + טקסט קצר)
3. סיפור / על העסק (פסקה אחת)
4. 2 עדויות לקוחות
5. טופס השארת פרטים
6. פוטר עם פרטי קשר

עיצוב: [צבעים]. [סגנון — מינימליסטי / חם / מקצועי]. רספונסיבי למובייל.
מלכודות נפוצות

3 שגיאות להימנע מהן.

01

פרומפט עמום

"תבנה לי אתר יפה" — Claude לא יודע מה זה יפה. הוא ינחש, וזה יהיה גנרי.

פתרון: תפקיד + מטרה + קהל בכל פרומפט ראשון.

02

5 שינויים בפרומפט אחד

"תוסיף סקציה, תחליף צבעים, תשנה פונט, תוסיף סרטון..." — חלק מהשינויים יבולבלו או יישכחו.

פתרון: שינוי אחד = פרומפט אחד.

03

לוותר אחרי 2 איטרציות

הדף הראשון תמיד לא מושלם. אחרי 5-7 איטרציות התוצאה משתפרת משמעותית.

פתרון: תכננו לעצמכם 5+ איטרציות לכל דף.

משימה לפני המפגש הבא

מה לעשות השבוע.

המשימה הזו תכין את הבסיס לשיעור הבא. מומלץ להקדיש לה 30-45 דקות.

1.
מלאו את ה-Brief לעסק שלכם 5 הרכיבים: תפקיד, מטרה, קהל, התנגדות, סגנון. כתוב הכל בקובץ Word/Notion.
2.
הריצו את התבנית מול Claude Code קבלו דף ראשוני. אל תשנו עיצוב עדיין — זה יבוא בשיעור 2.
3.
בצעו 3 איטרציות שיפור כפי שראינו בהדגמה — שינוי אחד בכל פרומפט.
4.
שתפו צילום מסך בקבוצת ה-WhatsApp תקבלו פידבק מחברי הקורס — איך אפשר לשפר, מה עובד, מה חסר.
אם נשאר זמן

תרגול נוסף לבחירה.

אחרי שסיימתם את המשימה — מי שרוצה להעמיק, יש 3 וריאציות שאפשר לנסות. כל אחת בונה על אותה תבנית, רק במבנה שונה.

תרגול A

דף "אודות"

בקשו מ-Claude לבנות דף "אודות" לעסק שלכם — סיפור אישי, מה מניע אתכם, מה ייחודי. אותה תבנית, פוקוס שונה.

תרגול B

דף שירותים

4 שירותים, כל אחד עם תיאור קצר ומחיר. תבנה לכם דף קטלוג נקי — שימושי לבעלי עסקים שמציעים שירותים מרובים.

תרגול C

דף "צרו קשר"

טופס מורחב, מפה, שעות פתיחה, רשתות חברתיות. דף משלים שכמעט כל אתר עסקי צריך.

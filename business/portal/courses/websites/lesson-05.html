מהשיעור הקודם

איפה נשארנו.

בשיעור 4 הוספנו SEO מלא — meta tags, OG tags, sitemap, robots.txt. הדף מוכן לאוויר. היום נעלה אותו לאינטרנט באמת — שכל אחד יוכל להיכנס מהטלפון שלו ולראות אותו על דומיין משלכם.

לפני שמתחילים

מונחים חדשים בשיעור.

Hostingהשירות שמחזיק את הקבצים של האתר שלכם ומגיש אותם למי שמבקש.בקורס נשתמש ב-Netlify (חינם).
Domainהכתובת של האתר באינטרנט. דוגמה: my-business.co.il.נרכשים חד-פעמי + תשלום שנתי. מ-30₪ עד 200₪ לשנה.
DNSמערכת שמתרגמת דומיין למיקום השרת. כמו ספר טלפונים של האינטרנט.שינוי DNS לוקח עד 24 שעות להתפשט.
SSL · HTTPSאבטחת תקשורת בין האתר לגולש. הסמל של מנעול בדפדפן.חובה היום — בלי זה גוגל מסמן את האתר כ"לא מאובטח".
GitHubשירות שמאחסן את הקוד שלכם בענן ושומר היסטוריית שינויים.חינמי לחלוטין לשימושים פרטיים.
Netlify / Vercelשירותי הוסטינג שמחוברים ל-GitHub ועולים אוטומטית בכל שינוי.שניהם חינמיים לאתר עסקי קטן.
Analyticsמערכת שעוקבת אחרי גולשים — מי, מאיפה, מה הם עושים, כמה זמן.Google Analytics — חינמי. מתחבר תוך 5 דקות.
חלק עיוני · 20 דקות

איך אתר חי באינטרנט.

לפני שמעלים — נבין מה קורה מאחורי הקלעים. כשמישהו מקליד דומיין, מה בעצם קורה?

חלק עיוני

5 שניות אחרי שגולש מקליד את הכתובת.

1.
הגולש מקליד "my-business.co.il"הדפדפן שואל את ה-DNS: "איפה השרת של הדומיין הזה?"
2.
DNS מחזיר כתובת IP"השרת של Netlify ב-[IP]". הדפדפן מתחבר לשם.
3.
Netlify מקבל את הבקשהבודק איזה אתר זה (לפי הדומיין), שולף את הקבצים שלכם.
4.
הדפדפן מקבל את הקבציםHTML, CSS, JavaScript. מתחיל לרנדר את הדף.
5.
הגולש רואה את האתרזה הכל. הסה"כ — 200-500 מילישניות.
חלק עיוני

למה GitHub + Netlify ולא משהו אחר?

בקצרה

GitHub שומר את הקוד שלכם, Netlify לוקח אותו ומעלה אותו לאוויר. השינוי שלכם בקוד → push ל-GitHub → Netlify מעדכן את האתר אוטומטית.

שניהם חינמיים לאתר עסקי קטן-בינוני. אין מגבלת תעבורה, אין הפתעות.

החלופות

WordPress: הרבה יותר כבד, פגיע לפריצות, צריך לעדכן כל הזמן.

Wix: נעול. אי אפשר להוציא את הקוד. אם רוצים לעבור — מתחילים מאפס.

שרת משלכם: 50$ לחודש, צריך מומחה לתחזק.

חלק עיוני · דומיין

איך לבחור דומיין?

DO · מומלץ

קצר, קל לזכור, .com או .co.il

שם החברה / שם השירות. אורך 6-15 תווים. אם השם תפוס — הוסיפו "il" / "online" / מילה קשורה.

my-business.co.il
cohenclinic.com

DON'T · להימנע

ארוך, מבלבל, סיומות לא מוכרות

אל תיקחו .biz, .info, או דומיינים עם מקפים מרובים — הם לא משדרים מקצועיות.

my-best-business-services.biz
cohen-shen-yam-rofa.online

איפה לקנות: Cloudflare Registrar (הזול ביותר, ~10$ לשנה ל-.com), GoDaddy (פופולרי בארץ).

חלק מעשי · 30 דקות

מעלים לאוויר.

4 שלבים, ובסוף האתר חי באינטרנט עם דומיין משלכם. עוקבים יחד.

הדגמה · שלב 1 — GitHub

העלאה ל-GitHub.

GitHub יישמור את הקוד שלכם בענן.

1.
נכנסים ל-github.com ונרשמיםחינמי. שם משתמש קצר, מייל, סיסמה.
2.
"New repository" — שם וסטטוסשם: my-business-website. סטטוס: Public (ציבורי). אל תסמנו "Add README".
3.
אומרים ל-Claude לעלות את הקודהוא יבצע git init, git add, git commit, git push — בלי שתצטרכו לגעת.
פרומפט · העלאה ל-GitHub תעלה את כל הקוד של האתר ל-repository שלי ב-GitHub. הכתובת: github.com/[שם משתמש]/my-business-website. תעשה git init אם צריך, git add ., git commit עם הודעה משמעותית, ו-git push. אם דורש אימות — הכנס token שאני אספק.
הדגמה · שלב 2 — Netlify

חיבור ל-Netlify.

תוך 60 שניות — האתר חי באוויר.

1.
נכנסים ל-netlify.com"Sign up with GitHub" — קליק אחד.
2.
"Add new site" → "Import an existing project" → GitHubבוחרים את ה-repo שיצרתם.
3.
"Deploy site"תוך 30 שניות — האתר חי בכתובת כמו amazing-cake-1234.netlify.app
4.
בודקים שהכל עובדפותחים את הכתובת בדפדפן ובמובייל. אם משהו לא עובד — חוזרים ל-Claude לתקן ו-push.
הדגמה · שלב 3 — דומיין

חיבור דומיין משלכם.

אחרי שיש דומיין שרכשתם — מחברים אותו ל-Netlify.

1.
ב-Netlify: Site settings → Domain management → Add custom domainמזינים את הדומיין שרכשתם.
2.
Netlify יראה לכם 2 רשומות DNSA record + CNAME record. שמרו אותם.
3.
נכנסים לאיפה שקניתם את הדומיין → DNS(Cloudflare / GoDaddy / וכו') — מוסיפים את 2 הרשומות ש-Netlify נתן.
4.
ממתינים 5 דקות עד שעההדומיין מצביע לאתר. SSL מוגדר אוטומטית — הסמל של 🔒 מופיע.
הדגמה · שלב 4 — אנליטיקס

הוספת Google Analytics.

בלי אנליטיקס — אתם לא יודעים מי באמת נכנס לאתר.

1.
נכנסים ל-analytics.google.comנרשמים עם Gmail. מקצרים את ההגדרה.
2.
יוצרים Property חדששם — שם החברה. תחום — מדינה. סוג — Website.
3.
מקבלים Tracking IDנראה כמו G-XXXXXXXX. מעתיקים.
4.
אומרים ל-Claude להוסיף לדףהוא יוסיף את הקוד ב-<head>, יבצע commit, push. תוך דקה — Analytics פעיל.
פרומפט · הוספת Analytics תוסיף Google Analytics לאתר עם המזהה G-XXXXXXXX (אעביר). תוודא שהקוד מוטמע בכל דפי האתר (לא רק ה-index), ב-<head>. אחרי זה תעשה commit ו-push לעדכן את האתר החי.
וריאציות

תוספות לפי צרכים.

אחרי שהאתר חי — יש דברים שאפשר להוסיף.

לפרסום בפייסבוק/אינסטגרם

אם תרצו לפרסם בפייסבוק — Pixel הוא חובה. מקבלים מזהה ב-business.facebook.com, נותנים ל-Claude.

תוספת B · Hotjar

הקלטות גולשים

הקלטות אנונימיות של גולשים באתר — לראות איפה הם תוקעים, מה לא ברור. חינמי לאתר קטן.

תוספת C · CDN

אצירה גלובלית

Netlify מספק CDN באופן אוטומטי — אבל אם רוצים יותר מהיר, Cloudflare בחינם מעל זה.

מלכודות נפוצות

3 שגיאות אחרי deploy.

01

שכחתם לעדכן את הדומיין ב-OG tags

ה-og:url עדיין מצביע ל-localhost או לכתובת Netlify הזמנית. הקישור בפייסבוק לא יעבוד.

פתרון: לבדוק ב-OG debugger אחרי deploy.

02

שינוי DNS לוקח זמן

קונים דומיין, מחברים, פותחים — לא עובד. נכנסים לפאניקה. לפעמים DNS לוקח עד 24 שעות.

פתרון: סבלנות. בדקו ב-dnschecker.org.

03

שכחתם להוסיף Analytics

האתר חי שבוע, מקבל גולשים, ואין מעקב. נתונים אבודים לתמיד.

פתרון: Analytics לפני שמכריזים על האתר.

משימה לסיום הקורס

המשימה האחרונה.

המטרה: האתר שלכם חי באוויר, על דומיין משלכם, מאובטח, ועם Analytics פעיל.

1.
העלו את הקוד ל-GitHub + Netlifyתוך 30 דקות — האתר על כתובת זמנית.
2.
רכשו דומיין וחברו אותוCloudflare Registrar הכי זול. אם אין — תזכרו שהמתנה ל-DNS עד 24 שעות.
3.
הוסיפו Google Analyticsוודאו שאתם רואים את הביקור הראשון בזמן אמת.
4.
שתפו את הלינק בקבוצההקישור החי לאתר שלכם. תקבלו פידבק מחברי הקורס + מסיבה קטנה — סיימתם את הקורס.

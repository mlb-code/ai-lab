יסודות אוטומציה + Make.com

מה זה אוטומציה, מה זה webhook, ומה זה API — כל זה ב-30 דקות בלי כאב ראש. אחר כך בונים אוטומציה ראשונה: טופס באתר → מייל ב-Gmail.

1. מה זה אוטומציה — באמת

אוטומציה זה תהליך שקורה לבד אחרי שמשהו מפעיל אותו. במציאות זה: ליד נכנס → מייל יוצא. תשלום בוצע → חשבונית נשלחת. קליק על מודעה → רשומה בגוגל שיט.

כל אוטומציה בנויה מ-2 דברים:

  • Trigger — מה גורם לתהליך להתחיל (טופס נשלח, מייל מתקבל, וכו')
  • Actions — מה קורה אחרי (שליחת מייל, רישום בטבלה, פתיחת משימה)

2. הכלים — מה לבחור

שלושה שחקנים עיקריים בשוק ה-no-code automation:

Make.com (לשעבר Integromat)

הכי גמיש, הכי חזק. תוכניות חינמיות עם 1,000 פעולות בחודש. בחירה ראשונה לקורס. ויזואלי, נחמד לעין, יודע לחבר כמעט הכל.

Zapier

הכי ידידותי, הכי מוכר. גרסה חינמית מאוד מוגבלת (100 פעולות בלבד), משם זה משתלם פחות מ-Make. טוב לאוטומציות פשוטות מאוד.

n8n

הכי טכני. אופן-סורס, אפשר להריץ על שרת משלכם בחינם לחלוטין. הכלי לאוטומציות חזקות במיוחד — נדבר עליו במפגש 3.

3. רישום ל-Make.com

  1. נכנסים ל-make.com
  2. Sign up Free עם Gmail (אפס חיכוך)
  3. הממשק: Scenarios = אוטומציות, Connections = שירותים שחיברתם

4. האוטומציה הראשונה — טופס → מייל

אנחנו ניקח את הטופס מהאתר שבניתם (Web3Forms שלמדנו בקורס 1) ונעשה משהו חכם איתו: כל פנייה תיכנס לגוגל שיט עם תאריך + שעה.

  1. Trigger: Webhook (Make ייתן לכם URL)
  2. Action 1: Google Sheets → Add a Row
  3. Action 2: Gmail → Send Email (התראה לעצמכם)
  4. Action 3: WhatsApp דרך Twilio (התראה למובייל!)

נחבר את הטופס מהאתר ל-Webhook הזה — וכל פנייה תופיע גם בגוגל שיט וגם תקפיץ לכם הודעה.

5. בדיקה בחיים אמיתיים

ממלאים את הטופס באתר שלכם. תוך 5 שניות:

  • ✓ שורה חדשה בגוגל שיט עם הפרטים
  • ✓ מייל בתיבה שלכם
  • ✓ הודעת WhatsApp במובייל
💡 רגע השיא

זה הרגע שבו רוב התלמידים אומרים "וואו, זהו? זה כל הסיפור?". כן. זה כל הסיפור. עכשיו דמיינו מה אפשר לעשות עם זה.

אוטומציות מכירה ושיווק

בונים pipeline מכירה אוטומטי — מהרגע שליד נכנס ועד שהוא לקוח משלם. כולל מיילים אוטומטיים, תזכורות, ולוגים מסודרים.

1. ה-Pipeline שאנחנו בונים

ליד מילא טופס באתר. מה הוא חווה אחר כך?

  1. תוך 30 שניות — מקבל מייל ברוכים הבאים מותאם אישית
  2. תוך 5 דקות — נכנס לגוגל שיט (ה-CRM שלכם)
  3. אחרי 24 שעות — מקבל תזכורת אם לא ענה
  4. אחרי 3 ימים — מקבל מייל "case study" של לקוח דומה
  5. אחרי 7 ימים — אם עדיין לא ענה, מועבר ל"לידים קרים"

הכל אוטומטי. אתם רק מסתכלים על הגוגל שיט בבוקר ורואים מי חם.

2. כתיבת מיילים מותאמים אישית עם AI

במקום לשלוח את אותו מייל לכולם — אנחנו ניתן ל-Claude לכתוב מייל מותאם אישית לכל ליד, על בסיס המידע שהוא נתן בטופס.

המבנה ב-Make

Trigger (Form) → HTTP Module → קריאה ל-Claude API עם פרטי הליד → קבלת המייל → שליחה ב-Gmail

תוצאה: כל ליד מקבל מייל שנראה כאילו אתם כתבתם אותו אישית. הם לא יודעים שזה אוטומטי.

3. תזכורות חכמות

ב-Make יש מודול בשם Scheduler — רץ פעם ביום על הגוגל שיט שלכם, בודק לידים שלא נענו, ושולח תזכורת אוטומטית.

הכלי הזה לבד יכול להעלות לכם את אחוז ההמרה ב-30%, רק בגלל שאתם לא שוכחים אף ליד.

4. שילוב עם CRM אמיתי (אופציונלי)

אם יש לכם CRM אמיתי (HubSpot, Pipedrive, monday.com) — Make מתחבר לכל אחד מהם. אנחנו נראה איך לחבר ל-monday כדוגמה — כי זה הכי נפוץ בישראל.

5. דוח שבועי אוטומטי

כל יום ראשון בבוקר — מייל אליכם עם הסטטיסטיקות של השבוע: כמה לידים נכנסו, אחוז המרה, מקור הליד הכי חזק. הכל אוטומטי, ב-Make.

אוטומציות פנימיות + AI

אוטומציות שחוסכות זמן בעבודה היומיומית — חשבוניות אוטומטיות, סיכום פגישות, תיוג מיילים, וכלי AI שעוטף הכל.

1. חשבונית אוטומטית מטופס

תשלום בוצע → חשבונית נשלחת. בלי שתעשו כלום.

אינטגרציה: Stripe / PayPal / Lemon Squeezy → Make → iCount / Hashavshevet / Greeninvoice → אוטומטית מייל ללקוח עם החשבונית.

אם אתם עוסקים מורשים בישראל — Greeninvoice יש לו API מצוין שעובד מצוין עם Make.

2. תיוג מיילים אוטומטי עם AI

כל מייל שנכנס ל-Gmail עובר דרך Claude:

  • "זה ליד חם"
  • "זו תלונה"
  • "זה מייל פנימי, ניתן להתעלם"
  • "זו פניית תמיכה"

בהתאם לתיוג — Make מצמיד תווית בגוגל, מעביר לתיקייה, או שולח התראה במקום שמתאים.

3. סיכום פגישות זום אוטומטי

זום מקליט פגישה → Make לוקח את ההקלטה → שולח ל-Whisper של OpenAI לתמלול → שולח ל-Claude לסיכום → הסיכום נכנס לגוגל שיט.

תוך 10 דקות אחרי הפגישה — יש לכם סיכום מסודר של מה שדובר, מה שהוחלט, ומה לעשות הלאה.

4. n8n — אוטומציות מתקדמות בחינם

אם אתם מתחילים להגיע לתקרת ה-1,000 פעולות של Make בחודש — n8n זו האלטרנטיבה. אופן-סורס, אפשר להריץ על שרת משלכם בחינם לחלוטין.

במפגש נראה איך מקימים n8n על Railway (5$ לחודש לשרת אישי) ומעבירים אליו את האוטומציות המסיביות.

5. עיצוב אוטומציה לעסק שלכם

החלק החשוב ביותר. כל תלמיד יזהה ב-3 דקות 3 תהליכים יומיומיים שלוקחים לו זמן — ואנחנו נבנה אחד מהם יחד.

הקוד והרעיון יישארו אצלכם. תוכלו להעתיק את ה-2 הנותרים בעצמכם.

💎 איפה אתם נמצאים בסוף הקורס?

יש לכם 3-5 אוטומציות שרצות בעסק שלכם. אם הן חוסכות לכם 5 שעות בשבוע (זה הממוצע) — זה 20 שעות בחודש. שעת עבודה של בעל עסק = 100-300₪. עשו חשבון.

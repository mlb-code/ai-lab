Claude Desktop + MCP — היסודות

מבינים את ההבדל בין צ'אטבוט לסוכן AI. מתקינים Claude Desktop, מחברים את ה-MCP הראשון, ובונים עוזר שמסכם מיילים בבוקר.

1. למה לא ChatGPT?

ChatGPT הוא צ'אטבוט. הוא יודע לדבר, אבל הוא לא יכול לעשות. הוא לא רואה את המיילים שלכם, לא ניגש ליומן שלכם, לא יכול ליצור משימה ב-Notion.

עוזר AI אמיתי = סוכן. הוא יכול לבצע פעולות. לקרוא קבצים. לשלוח מיילים. לקבוע פגישות. לעדכן מסד נתונים. הוא סוגר את הלולאה.

2. Claude Desktop + MCP

Claude Desktop זו האפליקציה של Anthropic ל-Mac/Windows. ההבדל מהדפדפן: Claude Desktop יכול להתחבר ל-MCP servers.

MCP — Model Context Protocol

פרוטוקול שאיתו Claude מתחבר לכל אפליקציה: Gmail, Calendar, Notion, Slack, Linear, GitHub, Google Drive — כל אחד מהם מציע MCP Server שאתם מחברים פעם אחת, ואז Claude יכול לעבוד עם הנתונים שם.

3. התקנה

  1. הורדה: claude.ai/download
  2. התקנה רגילה (Mac: drag to Applications. Windows: next-next-finish)
  3. חיבור עם החשבון שלכם (אותו אחד מהקורס הראשון)

4. ה-MCP הראשון — Filesystem

נתחיל פשוט. נאפשר ל-Claude לראות את התיקיות שלכם:

# בקובץ ההגדרות של Claude Desktop:
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/Documents"]
    }
  }
}

אחרי restart ל-Claude Desktop — תוכלו לכתוב לו "מה יש בתיקיית Documents שלי?" והוא יראה.

5. ה-MCP הראשון לעסק — Gmail

חיבור ל-Gmail דרך MCP. בקורס נעשה את זה יחד שלב-אחר-שלב. אחרי החיבור, אפשר לכתוב ל-Claude:

  • "תסכם לי את כל המיילים מהבוקר"
  • "אילו מיילים דחופים?"
  • "תכתוב טיוטת תשובה למייל מ-יוסי"

הוא קורא, מסכם, מציע. אתם מאשרים לפני שליחה.

6. בניית פרומפט סיכום בוקרי

פרומפט שתשמרו ותריצו כל בוקר:

Morning Brief

"תקרא את כל המיילים מ-24 השעות האחרונות. סווג אותם ל: דחוף / לתשובה / FYI / זבל. תן לי סיכום של כל קטגוריה. למיילים הדחופים — תכתוב טיוטות תשובה. תן לי גם 3 משימות עיקריות להיום על בסיס מה שראית."

3 דקות בבוקר → תפעלו עם בהירות מלאה כל היום.

חיבור ליומן + מיילים + משימות

מרחיבים את העוזר. מחברים את Google Calendar ו-Notion (או Todoist), והופכים אותו לעוזר שיודע לקבוע פגישות, לרשום משימות, ולתזכר אתכם.

1. חיבור Google Calendar

MCP Server לגוגל קלנדר. אחרי החיבור — אפשר לכתוב ל-Claude:

  • "מה יש לי השבוע?"
  • "תקבע פגישת זום עם דנה ביום שלישי בשעה 14:00, נושא: שיחת מכירה"
  • "מצא לי שעה פנויה ביום הרביעי הקרוב"
  • "בטל את הפגישה של ב-15:00 היום, ושלח התנצלות לכל המוזמנים"

2. חיבור Notion / Todoist

בוחרים אחד — איפה אתם מנהלים משימות. גם ל-Notion וגם ל-Todoist יש MCP Server.

אחרי חיבור: "תוסיף משימה — להתקשר ליעקב מחר בבוקר. תיוג: לקוחות. דחיפות: גבוהה."

3. ה-Workflow היומי

הזרימה האידיאלית:

  1. בבוקר: "סיכום מיילים + יומן + 3 משימות עיקריות"
  2. בצהריים: "מה עשיתי הבוקר? מה נשאר? תעדכן את ה-status"
  3. אחרי פגישה: "תרשום סיכום בנוטיון, תוסיף משימות שעלו, תזכר אותי לפעולות חוזרות"
  4. בערב: "סיכום היום, מה תכננתי לעומת מה שעשיתי, מה לתכנן למחר"

4. תזכורות חכמות

Claude לא רק מקבל פקודות — הוא יכול לתזכר אתכם. בעזרת cron jobs ב-Mac/Windows, אפשר להריץ פרומפטים אוטומטית בזמנים מסוימים.

דוגמה: כל יום ראשון ב-9 בבוקר — Claude שולח לכם אוטומטית את הסיכום השבועי לטלפון.

5. עוזר תיאור פגישות

משלבים את כל מה שלמדנו: לפני כל פגישה ב-Calendar, Claude מכין לכם brief: מי האדם, מה הקשר אליכם, מה דובר במייל האחרון, איך להיכנס לשיחה.

עוזר חיפוש + ידע + flow מלא

Claude לומד את העסק שלכם. מחברים אותו לכל המסמכים, המיילים ההיסטוריים, וה-CRM — והוא הופך לעוזר שיודע יותר עליכם מכל עובד אנושי.

1. חיבור Google Drive / Dropbox

MCP ל-Drive — Claude קורא את כל המסמכים שלכם. הוא יכול לחפש בתוכם, לסכם אותם, להשוות גרסאות.

  • "מצא לי את החוזה האחרון שחתמתי עם דיגיטל-X"
  • "השווה בין הצעת המחיר הזו להצעה הקודמת"
  • "תכתוב לי הצעת מחיר ללקוח X על בסיס התבנית הסטנדרטית שלי"

2. בניית "מוח" לעוזר — Knowledge Base

תיקייה מסודרת ב-Drive עם:

  • הסיפור של העסק שלכם
  • השירותים והמחירים
  • תהליכי עבודה סטנדרטיים
  • FAQ של לקוחות
  • סגנון הכתיבה שלכם (3 דוגמאות מיילים)

הוא יקרא את הכל, ויוכל לכתוב במקומכם בקול שלכם.

3. עוזר ב-Slack / WhatsApp

אם אתם רוצים לפנות לעוזר מהטלפון — אפשר לחבר אותו ל-WhatsApp או Slack. בונים בוט פשוט שכל הודעה אליו עוברת ל-Claude עם MCPs מחוברים.

תוצאה: שולחים הודעה ב-WhatsApp לעצמכם — מקבלים תשובה מהעוזר תוך 3 שניות, גם כשאתם בנהיגה.

4. אוטומציה + עוזר = שילוב מנצח

משלבים את מה שלמדנו בקורס 2: Make מפעיל את Claude לפי triggers, Claude מבצע פעולות חכמות, ומחזיר תוצאה ל-Make לפעולה הבאה.

דוגמה: ליד נכנס → Claude קורא את פרטי הליד + ההיסטוריה ב-CRM → כותב מייל מותאם → שולח. אתם רואים את התוצאה בגוגל שיט בלי להזיז אצבע.

5. הצגת פרויקט סיום

כל תלמיד מציג את העוזר שלו ואיך הוא משלב אותו בחיי היום-יום. מקבלים פידבק מהקבוצה, רעיונות לשיפור, ויש לכם רשימה של 5 דברים נוספים לבנות בעצמכם.

🚀 בסוף הקורס

העוזר שלכם חוסך לכם 1-2 שעות ביום. בחישוב שנתי — מעל 500 שעות. שעה של בעל עסק שווה 100-300₪. עשו חשבון. ואז עשו עוד חשבון.
